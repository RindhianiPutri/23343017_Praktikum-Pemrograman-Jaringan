# 📘 23343017_Praktikum-Pemrograman-Jaringan

## 🌐 Pemrograman Berbasis Jaringan – Node.js

Repositori ini berisi kumpulan **Jobsheet Praktikum Pemrograman Berbasis Jaringan** menggunakan **Node.js dan Express.js**.  
Materi disusun secara bertahap, mulai dari pengenalan Node.js hingga pembuatan web server dan pengembangan **JSON HTTP Endpoints** terintegrasi dengan API eksternal.

Setiap folder jobsheet dilengkapi dengan:
- 📄 `README.md` → penjelasan materi & hasil pembelajaran  
- 📁 Folder dokumentasi (screenshot/ss) sebagai bukti praktikum
